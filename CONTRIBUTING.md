# Contributing

Thank you for helping. This repository is a snapshot: the clients are
developed together with the Einar Gate API in Einar Gate's own repository,
where a change to the API does not build until the clients match it. Most
of each client's code is generated from [openapi.json](./openapi.json), and
a snapshot replaces this repository's content.

- **Issues are welcome**: bugs, confusing behaviour, missing documentation,
  or a language you need. Include the request id from the error message if
  a call failed.
- **Pull requests are read, not merged.** We port the change into the main
  repository, and it arrives here with the next snapshot, credited in its
  commit message.
- **Security issues** go to Einar Gate privately, through the support
  contact on [einargate.com](https://einargate.com), not to an issue.
  Never post an API key value: if one leaked, rotate it in the Einar Gate app
  at once.
